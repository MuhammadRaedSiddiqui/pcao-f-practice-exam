Configure the browser project token/host in environment variables; development and production reports are separated with an `environment` event property. Automatic click capture and session recordings are disabled. See [POSTHOG_SETUP.md](POSTHOG_SETUP.md) for dashboard cards, active-time queries, data boundaries and production configuration. Run `npm run test:analytics` for the separate intercepted-SDK Chromium suite.

Optional email/password accounts, without email verification, are implemented locally for completed-report backup, recovery and account/report management. Account settings are available at /settings and attempt history at /history; exports are available for individual Results reports as PDF. The linked workspace has Supabase configured and its migration/functions deployed. Signup automatically backs up completed guest browser history and enables backup for future completed exams; an empty browser starts with empty account history. Users can turn automatic backup off in Account settings; sign-in preserves existing preferences. Sign in and Create account are in the shared header. Other installations keep accounts disabled until configured. See [SUPABASE_SETUP.md](SUPABASE_SETUP.md) and [CLOUD_HISTORY_VERIFICATION.md](CLOUD_HISTORY_VERIFICATION.md). Active exams keep their original browser persistence and deadline.

New exams begin with a difficulty-selection dialog. Intermediate is selected by default on every opening, including after cancelling an Advanced choice. The primary button reads **Start Exam** for either level. The three comparison bullets describe reading load, interacting constraints, and structured evidence, using the approved wording based on both reviewed banks.

Intermediate uses `public/easy-question-bank.json` version 1.0.0; Advanced uses `public/question-bank.json` version 1.1.0. Both reviewed banks are available and load independently. New attempts save their difficulty and bank snapshot; older records display "Original exam" and remain readable. The Source courses drawer shows one shared course list for Intermediate and Advanced without a difficulty toggle. See [INTERMEDIATE_INTEGRATION_VERIFICATION.md](INTERMEDIATE_INTEGRATION_VERIFICATION.md) for the original integration evidence and [PROJECT_IMPLEMENTATION_STATUS.md](PROJECT_IMPLEMENTATION_STATUS.md) for subsequent changes.

A browser-saved PCAO-F practice exam with optional Supabase account backup of completed reports. Each difficulty loads its own reviewed 60-question, 120-minute dataset at runtime. Existing attempts keep their original frozen bank snapshots for answering, grading, and review. Results and history show an equal-weight practice score out of 1000 and practice Passed/Failed at an unrounded 720 threshold. These are not official certification scores. Incomplete selections count as Unanswered before submission and Incorrect afterward. The home Source courses drawer lists ten courses without question-specific references.

Saved attempts synchronize across tabs, reject stale changes, and finalize on the Start page when their deadline passes. Saving requires a browser with Web Locks; read-only reports remain available without coordinated saving. Older records keep their original snapshots and grades.

Results includes **Export report (PDF)**, which downloads scores, attempt metadata, domain results, review priorities, and all saved question reviews regardless of the active filter. Export works offline once its module has loaded and does not change browser storage. The Intermediate Exam header, Results and PDF reports display "Independent PCAO-F Practice — Intermediate" while preserving the reviewed bank title and frozen snapshots.
