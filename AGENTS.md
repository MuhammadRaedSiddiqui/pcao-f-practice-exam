# Repository Guidelines

## Project Structure & Module Organization

This app uses React, TypeScript, and Vite with optional Supabase accounts for completed-report backup. `src/App.tsx` coordinates Start, Exam, Review and Results; `src/ui/ResultsPage.tsx` renders completed snapshot reports; `src/styles.css` contains responsive styles. Keep validation, attempt, and Results summary logic in `src/domain/`, reusable controls and Markdown rendering in `src/ui/`, and runtime data in `public/question-bank.json` (Advanced) and `public/easy-question-bank.json` (Intermediate). Unit tests are in `tests/*.test.ts(x)`, browser tests in `tests/browser/`, and synthetic fixtures in `tests/fixtures/`. Read [PROJECT_IMPLEMENTATION_STATUS.md](PROJECT_IMPLEMENTATION_STATUS.md) for the unified implementation and current status. Read [IMPLEMENTATION_SPEC.md](IMPLEMENTATION_SPEC.md) before changing the flow or schema.
