## Version-only transformation proof

For each pilot, the existing draft is projected to approved status **in memory only**, exactly as for its historical prospective g1. The same projected entry and source are passed first with 1.0.0 and then with 1.1.0; **only the version argument differs**. All ten new g1 values differ, while all ten draft SHAs, q1 values and review IDs remain unchanged.

Every educational field is preserved: question ID/source fingerprint, all three hints and their order, decisive criteria, reasoning, every original-option comparison and its order, strongest-distractor IDs, vocabulary, source-check claims/locators/indices and review ID. Original domain, stem, options, key/cardinality, explanations, source titles/sections/URLs and source tuple are unchanged. Approval.status is the same approved projection for both g1 computations; the stored drafts stay draft. No reviewedAt timestamp, new review ID or extra metadata is added to a GuideEntry. The proof checks the entire entry object, not selected prose fields. Both banks, all seven authoring files, source ledgers and approval history are protected by byte hashes.
