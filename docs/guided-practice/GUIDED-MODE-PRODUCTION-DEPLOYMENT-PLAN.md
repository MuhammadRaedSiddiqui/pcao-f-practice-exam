Retain matching JS/CSS/PDF chunks, routing/cache/service configuration and a verified host deployment identifier in the rollback package. There is currently **no starts-only pause**. Feature-off and empty-catalog rollback preserve stored bytes but block saved-session guidance/resume and new starts. They are emergency suspension options with user impact, not compatible continued service. Owner D5 must choose triggers (for example confirmed privacy/protection or persistence defect, wrong approval/hash, critical supported-browser failure), operator and communication/return-to-service policy. Do not assume a revocation of one version automatically covers the other, or leave a known unsafe lineage enabled accidentally. Preserve original educational/approval history even if access is suspended. No withdrawal, rollback package publication or rollback rehearsal was performed here.
