## Scope, facts and invariant register

Guided Practice teaches scenario interpretation, relevant evidence, constraints, business vocabulary, plausible alternatives and independent reasoning. It is an untimed separate learning pathway with three optional progressive hints. A learner commits an exact-cardinality answer before seeing correctness or full reasoning; that first commitment is permanently locked for the session. Post-exam Guided Review is a new retry experience over compatible completed-report snapshots, with Incorrect & Unanswered as default, Flagged and All Questions alternatives. Original report selections are never copied into the retry controls.

Verified current architecture is React/TypeScript/Vite, a mounted App under React Router, strict Zod runtime banks, pure attempt/results modules, localStorage Mock records, Web Locks/revisions and frozen full-bank snapshots. Optional Supabase backs up completed reports; optional PostHog and PDF export already exist. Guided must remain usable as a guest without adding services or runtime AI. D1–D11 are approved architecture requirements; new paths remain future capabilities, not implemented code. D12–D14 remain future decisions.
