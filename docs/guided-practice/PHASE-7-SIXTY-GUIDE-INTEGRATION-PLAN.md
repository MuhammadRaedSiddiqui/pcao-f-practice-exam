## Revocation, rollback and historical feedback

Revocation is exact-digest and source/version specific. Retain the corresponding approvedEntries identity even when withdrawing it, so release integrity remains checkable; selectors exclude the revoked item and a frozen session containing it must become unavailable without mutation. An unrelated withdrawal must not rewrite an existing safe session. A logical educational defect affecting a pilot in both versions requires an explicit decision for **both old 1.0.0 and new 1.1.0 g1 values**. No automatic cross-version revocation or unrevocation exists. Source/guide changes cannot bypass an old withdrawal by choosing a fresh version; assess lineage deliberately. Historical feedback remains the exact saved item/prose and first commitment, never replaced by current release feedback.

The future rollback package must pair a compatible reader/build with exact safe maps, revocation decisions, both relevant immutable assets and a deployment manifest. A pre-integration build with the current empty catalog is **not** a resume-compatible rollback for later 1.1.0 sessions. Preserve safe 1.1.0 catalog authorization even when rolling back unrelated UI/code. Do not move the ten-item legacy row last as an implicit policy rollback: it would make new starts ten-item/1.0.0, contrary to the selected policy. Compatible rollback can retain the approved 1.1.0 selection while reverting unrelated behavior, or use a separately authorized starts-pause design with safe readers/maps retained.

There is no existing starts-only pause switch: [GuidedPractice](../../src/ui/guided/GuidedPractice.tsx) gates the entire interface on guidedEnabled. Turning the feature off preserves data but blocks **both new starts and resume**, even with maps retained. Treat that as a disclosed emergency suspension, not successful historical compatibility. A resume-only rollback/pause would need separately scoped implementation and tests. Unsafe content must stay unavailable rather than be silently migrated or reauthorized. Rollback approval and actual-host smoke remain release gates.
